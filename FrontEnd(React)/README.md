### `FrontEnd`
This is the frontend code for the CoreDump Analysis Tool.

### `Installation/Integration`
The backend server should be up. Also make sure to change the BASE_URL in 'src/utils/axios.js' to the server's URL

### `npm start`
Use this command to run the application

### `(HOST=0.0.0.0 npm start)`
USe this to run the react server on HOST machine
